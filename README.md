# TripIt Shine Travel

> Exactly like [TripIt.com](https://www.tripit.com/) — but supercharged with 20+ plan types & micro-icons TripIt does not have.

**Live:** Open `index.html` (no build needed) or enable GitHub Pages after push.

## Beyond TripIt
- Airport Waiting queue timer + gate countdown
- Lounge shower / nap pod / prayer room icons
- Immigration + Baggage Live (carousel, AirTag, weight)
- Layover Planner, Packing Weight (23kg/7kg guard), Budget & Currency, eSIM, Photo Spots
- Timeline, Map, Document Vault, Offline-ready, Import via forwarding email

## Run
Just double-click `index.html`.

## Tech
Single-file HTML/CSS/JS, Font Awesome, localStorage persistence, print & ICS export.
